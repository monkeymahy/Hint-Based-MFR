# Hint-Based MFR

这是一个基于 Python OCC 的 STEP 模型特征识别程序。它参考论文
"Hint-based generic shape feature recognition from three-dimensional B-rep models"
中的思路，用零件的几何和拓扑关系识别三类制造特征：

- `1 hole`：孔
- `2 boss`：凸台
- `3 chamfer`：倒角

## 识别思路

程序不会只看单个面的形状，而是先把整个零件拆成一个“面之间的关系图”。每个面会记录：

- 面类型：平面、圆柱面、圆锥面等。
- 面积、中心位置、法向方向。
- 圆柱面或圆锥面的轴线方向和轴线位置。
- 圆柱面的 U 向覆盖范围。
- 圆边、完整圆边、直线边数量。
- 相邻面关系，以及哪些相邻关系来自内环。

当前识别顺序是：

1. 先用一条基于定义的 pass 统一识别孔（枚举 inward 圆柱侧壁 -> 分组 -> 判定完整 2π 圆周 -> 附加盲孔底面 -> 合并阶梯孔）。
2. 再识别倒角。
3. 最后用结构化规则统一识别凸台。

已经识别出的面不会被后续规则覆盖。凸台不再由“某个面是 outward 圆柱面”这种类型规则给出，而是由一个独立的结构化 pass 统一识别，下面单列说明。

## 孔的识别规则

孔的定义是：从零件中移除了一段圆柱形体积（`docs/definition.md`）。这个定义的可检特征是**完整的 2π 圆柱侧壁**--一圈没有断开的管壁。用户给出的三条实际口径：

- 侧壁被 STEP 拆开、**拓扑上不连接**的 -> 不是孔；
- 侧壁被切/被修饰、但**仍有完整 2π 圆周不断** -> 是孔；
- 盲孔底面必须**与这条完整圆周相连**、且**在圆周内部有面积**；底面自身可以有内环孔，不必铺满。

程序不再区分“内环孔 / 倒角桥接孔 / split 半圆孔 / 兜底孔”，而是用一条 wall-first pass 统一识别。多边形孔、纯平面侧壁开口继续不算孔。

### 单 pass 流程

1. **枚举 inward 圆柱**：所有径向值 `< -radial_threshold` 且带轴向/半径信息的圆柱面。
2. **按拓扑 + 共轴 + 同半径分组**：只沿共享 edge 做 BFS；两个面属于同一组，当且仅当**它们直接共享 edge** 并且轴向、轴线位置、半径都匹配（`_coaxial_same_radius`）。几何上共轴但拓扑不相连的两段半圆 -> 不同组（对应“拓扑上分开 -> 不是孔”）。
3. **闭合性检查**：组内所有面的 `u_span` 之和 `≥ 2π - hole_angular_coverage_tolerance`。任一半圆缺角、U 形槽、1/4 圆角都在这一步被排除。
4. **hint 校验（carrier）**：组必须能找到一个 hint 锚点，才算真正的孔而不是斜切穿过实体的圆柱片段。允许的锚点有两种：
   - **直接 carrier**：某个 wall 出现在其邻居面的 inner-loop 邻接中（Li et al. 的经典 hint：wall 位于 carrier 的内环里）。
   - **过渡桥 carrier**：wall 的邻居是 cone 或 torus 过渡面，而这个过渡面又落在某个 carrier 的 inner-loop 邻接中--即倒角/圆角挡住了入口，carrier 隔一层。

   没有 carrier 的 wall 组仍然可以是孔（保守起见，wall 本身自带证据），但**不允许附加盲孔底面**--一个拿不到 carrier 的圆柱片段最典型的成因是“斜平面切穿实体的圆柱截面”，把邻接平面当底面会漏进外壳。
5. **盲孔底面**（仅在 carrier 命中时启用，`_find_blind_bottoms`）：候选是与 wall 组共享 edge 的平面邻居。对每个候选平面 P：
   - 只考察它与 wall 共享的、类型为**完整/局部圆弧**的边，且圆弧半径与 wall 半径一致；
   - 把这些圆弧按“沿轴投影”分桶（一个桶代表一个轴向 z 位置的“嘴”）；
   - 桶内累计圆弧参数跨度 `≥ 2π - hole_angular_coverage_tolerance`，且这些边**位于 P 的外环**（wall 相对 P 是外环邻居，说明 P 沉在孔内部，而不是 mouth carrier）-> P 是这个位置的 blind bottom。
6. **合并阶梯孔（`_merge_stepped_holes`）**：若两个已确认的 hole feature 共享一个 shelf plane（它是一个 feature 的 blind bottom、同时是另一个 feature 的 carrier 邻接平面），且两个 feature 同轴，则通过 union-find 合并为一个 hole 实例，shelf plane 一并纳入。

### 孔包含哪些面

- 侧壁：wall 组内所有 inward 圆柱面。
- 盲孔底面：`_find_blind_bottoms` 判定通过的平面。
- 阶梯孔中间的 shelf plane：`_merge_stepped_holes` 合并后进入。

不进入孔的面：入口大平面（那是 mouth carrier）、桥接的 cone/torus 过渡面（保留原本 label；cone 通常留在 `other`）、以及所有和这个 wall 组无关的邻接面。


## 凸台的识别规则

凸台的本质是：从某个基准表面向外凸出的闭合形状。早期的类型化规则（“outward 圆柱面就是凸台”“一圈平面侧壁就是平面凸台”）会漏掉没有顶面的凸台、没有闭合侧壁的凸台，也会把结构上完全一样的凹槽误判成凸台。当前实现改用一个**结构化 pass** 统一识别凸台，不再区分圆柱凸台和平面凸台。

### 结构化定义

一个凸台实例必须同时具备三部分，以这个结构作为载体来识别：

1. **闭合侧壁环**：一圈侧壁面把一个开口围起来，并且这一圈不会“漏”到与凸台无关的外表面上。侧壁可以是圆柱面、平面、或自由曲面，混合也可以。侧壁也可以带内环（例如环形侧壁：外边界是凸台轮廓、内边界是穿台小孔）；这种侧壁的内环邻居是穿台孔的壁，属于凸台结构的一部分。
2. **顶面**：一个盖住侧壁环的顶面。顶面可以直接贴在侧壁上；如果顶面和侧壁之间隔着过渡面（倒角/圆角），那么“过渡面 + 顶面”一起盖住侧壁环也可以。
3. **底面**：凸台所凸出的基准表面。底面可以是任何面，只用来确定凸出方向，本身不进入凸台。

三部分缺一不可：只有侧壁没有顶面、或侧壁不闭合的结构，都不算凸台。

### 凸台与凹槽的区分

凸台和凹槽在结构上完全对称（都是一圈侧壁 + 顶 + 底），唯一能区分的是凸出方向：

- 圆柱侧壁用径向方向区分：`outward`（径向 > `0.2`）的是凸台，`inward` 的是孔/凹槽。
- 平面侧壁和自由曲面侧壁没有径向方向，改用相对底面法向的有符号偏移区分：侧壁中心落在底面法向正侧的是凸台，落在负侧的是凹槽。

### 种子与基准面

pass 从一个侧壁种子出发找凸台。种子有两种：

- **圆柱种子**：径向 `outward` 的圆柱面。这是无歧义的凸台种子。带内环的圆柱壁（壁上开着孔、或长着侧凸台的大圆柱壁）也可以作种子。
- **平面种子**：被某个内环 carrier 持有的平面侧壁，且该平面相对 carrier 凸出（有符号偏移为正）。只有能找到内环 carrier 的平面侧壁才作为种子，避免把凹槽的平面侧壁当种子。

找到种子后确定基准面（carrier）和**凸出轴**（protrusion axis，即凸台从底面升起的方向）。平面 carrier 的凸出轴就是 carrier 法向；曲面 carrier 的凸出轴改用 cap 平面的法向（因为曲面法向是径向、垂直于凸出方向）。分以下情形：

- **情形 A（内环 carrier）**：种子被某个带内环的面持有，那个面就是基准面。这是最经典的 hint：凸台从基准面上的一个孔里凸出来。
- **情形 A'（内环 carrier 被过渡面挡住）**：种子和 carrier 之间隔着一个圆角/圆锥过渡面时，carrier 的内环邻居是过渡面而不是侧壁本身，情形 A 会漏掉。允许跨过一个 cone/torus 过渡面去找 carrier：过渡面的邻居里若有带内环的面，即视为该侧壁的 carrier。
- **情形 B（外壁）**：圆柱侧壁通过基准面的外环连接（而不是内环），且该外环邻居平面扩展到侧壁的共轴同族之外。这说明它是零件外壳本身的圆柱壁，不是凸出物，直接拒绝。判定时把侧壁的共轴同族（同轴圆柱另一半等）视作"侧壁自身"，避免把两半圆柱共用的 cap 误判成底面。
- **情形 C（独立圆柱/装配）**：圆柱两端都是 cap、没有拓扑相连的基准面。这时做几何搜索：在与 cap 共面、法向对齐的所有平面里，找一个外边界**严格包含** cap 连接圆的面作为基准面。底面可能在装配体的另一个 solid 上，所以是几何搜索而非拓扑搜索。包含判定是形状无关的：把 cap 外边界采样成点，要求每个点都落在候选底面的外环多边形内部，且至少有一个点严格落在内部（防止把同尺寸重合面当成更大的底面）。**同时要求另一端是自由端**：只有当至少一个 cap 找不到这样的包含面（该端暴露在外，没有更大的共面接收面）时，才承认该凸台。两端都找到更大包含面的是贯穿连接件（如两个零件之间的连接杆），不是从单一表面凸出的凸台，直接拒绝。
- **情形 D（曲面 carrier）**：圆柱侧壁从一张非平面（如圆柱形本体）经外环凸出，没有更大的平面底面。此时 cap 平面（与侧壁轴对齐的端面）的法向作为凸出轴；侧壁的曲面邻居中，带内环且与侧壁**交叉轴**（侧壁轴不平行于曲面轴，以排除本体自身的同轴表面）的那一个作为 carrier。
- **情形 E（同轴法兰/凸缘，如螺钉头）**：一圈同轴 outward 圆柱侧壁（合成完整 2π 圆周）被一块带内环的轴对齐平面 cap 盖住，cap 的内环孔让一根**更细的同轴 outward 圆柱**（轴/杆）穿过（经 cone/torus 圆角过渡）。头部从轴上**径向**凸出，cap 在侧壁的轴向端而不是远端，所以轴向凸出模型（情形 A–D 的"顶面在侧壁外侧"）套不上，单独识别：环 + cap 合成凸台，杆作结构 hint（不进入）。杆必须是 outward（区别于带穿台孔的凸台--那种 cap 孔通向 inward 孔壁，不是杆）。**真正的 carrier 是头部另一轴向端（与 cap 相对）的轴对齐平面--头部坐落的底面**，从侧壁环的轴对齐平面邻居（头部底面碎片）或杆远端的轴对齐平面邻居（直连或经一层 cone/torus 圆角）可达。该底面常被头部、杆孔和邻近特征切成多个共面碎片（未必边相邻），所以按共面（同法向、同轴向偏移）做**全局**收集（非仅边相邻 BFS），测其相对杆轴的最大径向范围，要求**大于头部半径**（底面 > 包围面）：找不到这样的底面（杆悬空、以 tip 收尾），或底面不大于头部，都不算凸台。这取代了早先"杆长 > 径向凸出量"的代理判定--后者无法区分真底面与悬空杆，会把底面并不大于头部的情形误判为凸台。
- **情形 F（轴端实心旋钮/头部）**：和情形 E 同样是头部坐在细轴上，但头部是**实心**的--侧壁环的另一轴向端不是带孔的 cap，而是一块实心的轴对齐平面（顶面），轴在顶面的对侧（环的远端）经 cone/torus 圆角过渡接到更细的同轴 outward 圆柱（杆）。判据：一圈共轴同半径 outward 圆柱合成完整 2π 圆周；轴向一端找到轴对齐平面 cap（可隔一层 `chamfer` 锥面）；另一端经圆角过渡找到**更细**的同轴 outward 圆柱杆。carrier 复用情形 E 的底面判定（头部远端轴对齐平面、全局共面收集、径向范围 > 头部半径）。实例 = 环 + 顶面；杆、圆角和底面不进入。与情形 E 的区别：E 的 cap 带内环（杆穿过 cap 同一端），F 的顶面实心（杆在另一端）。

### 侧壁环生长

从种子出发做 BFS 扩展侧壁环。一个相邻面能加入环，需要：

- 相对 carrier 沿凸出轴凸出（和种子同向）。
- **横向性**（类型无关主判据）：面法向与凸出轴近似正交（绝对点积 ≤ `0.35`），即面朝向侧向、不是顶/底 cap。这对平面、自由曲面都成立。
- **类型特化**：圆柱侧壁额外要求 `outward` 径向，且与已有圆柱侧壁要么**共轴且同半径**（同一级凸台被 STEP 拆分成的侧壁段；不同半径或轴线位置不同的共轴圆柱属于不同轴向级别，不加入同一环），要么**同母线方向**（`axis_dir` 一致但轴线位置不同，且该墙被 carrier 内环持有--这是自由形状包围圈凸台，一圈不同轴的圆柱/平面围出一个非圆开口）。圆锥面和圆环面只作过渡面（倒角/圆角），不当侧壁。
- 侧壁可以带内环（环形侧壁，或壁上开孔/带侧凸台的大圆柱壁）。带内环的侧壁只有在内环邻居中出现**共轴同半径的 outward 片段**（同一级的碎片会误并进来）时才被拒绝；内环邻居若是别的凸台的侧壁（不同半径/不同轴位的 outward 圆柱，如主圆柱壁上长出的侧凸台），不阻止该侧壁入环。

如果遇到一个过渡面（倒角/圆角，即“桥”），桥本身不加入环、保持自己的标签，但允许穿过桥去认领桥另一侧共轴同半径的圆柱侧壁段。这样同一级被锥台/圆角分成几段的圆柱也能合成一个环；多级凸台的每一级各自成为一个独立的单级凸台实例分别判定。

### 闭合性检查

环要闭合：环里每个面的每个非侧壁邻居，必须是 carrier、与 carrier 共轴的曲面分片（split 圆柱 carrier 的另一半）、通向顶面的过渡面、环内另一个面、穿台孔壁、或**已被其他特征认领的面**（hole/chamfer/别的凸台实例的面--它们是特征边界而不是外表面泄漏）。穿台孔壁指侧壁内环邻居、`inward` 圆柱壁、或已被识别为 `hole` 的面--这些是凸台结构内的合法边界。带内环的邻居只有当它正好是盖住环的顶面时才算合法边界，否则视为环漏到了外表面上，拒绝这个凸台。

### 顶面与边界约束

顶面必须盖住侧壁环，且有两个约束：

- **位置约束**：顶面是与凸出轴严格对齐的平面（最终确认使用 `axis_alignment_confirm_threshold`），且顶面中心沿凸出方向的偏移必须严格大于所有侧壁环面（顶面在侧壁外侧，而不是和侧壁齐平或更靠内）。顶面可以带内环（孔穿过顶面），仍然合法。顶面可以**隔着过渡面**（倒角/圆角桥）连到侧壁--这时用几何判定（严格对齐 + 位置）确认顶面，桥的连通性由 BFS 保证，不要求顶面直接贴侧壁。
- **边界约束（不能超过侧壁）**：顶面 + 包住的凹陷壁组成的“盖子”外边界最多与侧壁顶边重合，不能超出。实现上检查盖子里每个面的每个邻居：必须是侧壁环面、carrier、盖子内另一个面、穿过顶面的孔壁、或已被其他特征认领的面（例如盖在顶面与侧壁之间的 `chamfer` 倒角圈、穿过顶面的孔壁、邻接的其他凸台面）；只要碰到任何一个仍未标注、与凸台结构无关的外表面，就说明顶面溢出了侧壁边界，拒绝这个凸台。顶面与侧壁之间可以隔**已标注的倒角面**（chamfer collar，如凸台顶口的锥形倒角圈）--顶面搜索的 BFS 会穿过 `chamfer` 面透明地到达顶面，但倒角面本身保持 `chamfer` 标签、绝不并入凸台。

### 包住的凹陷壁

只有一类被凸台结构完全包围的面会并入 `boss` 实例：**内向圆柱凹陷壁**（如带轮/线轴形凸台的颈部凹槽）。

判定方式：从侧壁环 + 顶面出发，BFS 收集所有未标注的内向圆柱面，再用 fixpoint 剔除任何碰到凸台结构外表面（非侧壁环面、非 carrier、非已收候选）的候选--只有完全被凸台包围的才保留。已标注的面（孔壁、倒角面）不收。

**cone/torus 过渡面不再并入凸台实例**（重新打标后，数据集中没有任何 cone 或 torus 属于 `boss`）：它们只作桥接（连接侧壁段或连接顶面），保持自己的标签（`chamfer` 或 `other`）。

### 比例约束（已移除）

早期的硬性比例约束“底面周长 / π > 凸台高度”（等价于圆柱底盘直径 > 高度）已**移除**：重新打标的数据集把高瘦的旋钮（底面明显小于高度）也标为 `boss`，说明该比例只是 aspect-ratio 先验而非凸台定义的一部分（V2 文档本身也建议把它降级为置信度惩罚或可配置开关）。若之后需要抑制销钉/细长件的误识别，可再以置信度形式引入。

### 扫描轮次与实例构成

侧壁种子的扫描做**两轮**：第一轮识别能独立闭合的凸台；第二轮带着第一轮的认领结果重扫剩余种子。这解决了凸台边界邻接到**靠后才发现的其他凸台**的情况--例如主圆柱凸台的侧壁上长着一圈侧凸台（面序靠后），第一轮里这些邻居尚未标注、闭合检查会把它们当作泄漏，第二轮里它们已是已认领的特征面、算合法边界。

满足全部检查后，侧壁环 + 顶面 + 包住的凹陷壁合成一个 `boss` 实例；倒角面（平面或锥面）保持 `chamfer`，cone/torus 过渡面保持原标签，carrier/底面不进入。

## 倒角的识别规则

倒角的本质是：两个非共面的正常表面之间，有一个较小的**过渡面**。过渡面有两种截面形态：

- **平面倒角**（AP224 的 "flat cross section"）：平面过渡面；
- **锥形倒角**（曲面截面）：圆锥过渡面（不要求完整回转），典型是沉头孔口的锥面（countersink）、圆形外缘的锥形倒角、以及大锥台/半环锥面等被标为倒角的锥形过渡。

一个平面会被识别为倒角（`_plane_is_chamfer`），判据是**纯几何/拓扑的，没有面积限制**：

- 它是平面、且**自身不带内环**（只有该面自己被打孔、作为 carrier 时才排除）。注意：仅仅与邻居的内环边相邻（`inner_loop_neighbors`）不排除——孔口/槽口倒角本来就贴着 carrier 的内环边，必须能识别。
- 它有两个**支撑面**（已被标为倒角的邻居不算），这两个支撑面与该平面的锐角都落在 `30°–60°`（`chamfer_preferred_min/max_angle`）；即倒角是两个支撑面之间等角（近 45°）的斜切面。圆柱支撑面的角度取**共享边处的径向法向**，而不是参数域中点的参考法向（后者在圆周任意位置，会把平行圆柱误判成垂直）。
- 这两个支撑面彼此**垂直**：法向点积绝对值 `< 0.05`（约对应夹角 `≥ 87°`，为 90° 留有小误差余量），且垂直度同样取共享边处法向。垂直对中**至少一个必须是平面**——两块互相垂直的圆柱壁之间夹的结构平面（如多柱交汇处的隔板）不算倒角，即使它们在参考点上的法向恰好垂直。非直角（如约 75° 尖角）处的斜切面也不算倒角。
- 拓扑上它是一个条带：`edge_count ≤ 6`。两个面之间的倒角条最多 6 条边（绕圆柱的倒角会被拆成 5–6 边），而多边形零件端面/凸台顶面有更多边。
- 支撑面可以是圆柱壁（含 outward 凸台侧壁）——凸台侧壁与顶面之间的平面倒角因此能被识别；防止多边形凸台顶面误判由垂直度（接触法向）+ 垂直对含平面 + 边数约束共同承担。

另有**三角角帽规则**：三条边、三个邻居，且三个邻居都已被识别为倒角、彼此两两不共边的小三角面（三面角处三个倒角条交汇的角帽，如 01012404），在固定点迭代中被补收。

平面倒角通过**按面积升序的固定点迭代**识别：每轮内面积小的条带先被标记，被条带包围的大结构斜面随即看到条带已是倒角、失去非倒角的垂直支撑对而被排除。这样不需要任何面积比较或绝对面积上限，就能把大斜面（被倒角条包围的零件斜面）与真正的窄倒角条分开。

一个圆锥面会被识别为锥形倒角，需要（`_cone_is_chamfer`）：

- 不带内环（带内环的锥面是被打了孔的结构锥台/沉座，不是倒角）；
- 非退化碎片（`u_span ≥ 0.05` 且面积 `> 1.0e-9`，排除由 STEP 分割产生的零宽度锥面接缝）；
- **不是两端封闭的锥台**：若锥面轴向两端都存在法向平行于锥轴的平面邻居（两个不同轴向偏移的端板），说明它是夹在两板之间的结构锥壁/漏斗壁，不是孔口倒角；只在一端有口部平面、另一端开口通向圆柱的才是沉头倒角（`_cone_has_two_end_planes`）。
- **存在两个支撑邻居，各自与该锥面的锐角落在 `10°–80°`，且这两个支撑面彼此垂直**（法向点积绝对值 `< 0.05`，约 ≥87°）。锥面参考点法向噪声大，所以支撑角区间比平面倒角的 `30°–60°` 放得更宽（多边形孔口的角部倒角锥面与其平面的实测角约 `15°`/`77°`），但两个支撑面必须构成直角转角——和平面倒角同一判据。**支撑面只允许平面或圆柱**；同族的锥面/环面/球面（同一回转体沿母线边相邻的分片）不算支撑面——它们在参考点上的法向会偶然垂直，但那是回转几何的假象，不是直角转角。圆柱支撑面的垂直度同样取共享边处的径向法向。

不要求锥面闭环：拐角处只覆盖局部弧段的不闭环锥面（如 01011489 `u≈2.92`、01013304 `u≈0.6–1.0`、12.step `u≈0.34–1.05`、各半环 `u=π`）只要有一对垂直支撑邻居就识别为倒角。一个锥面倒角常被 STEP 沿母线切成几片：两端的片拥有平面/圆柱支撑对能通过上述判据，中间的片只与同族锥面相邻、独自通不过；因此识别后做**同族锥面传播**（固定点）：与已标倒角的锥面共轴线、同半角的相邻锥面片一并补标为倒角，使整个被分割的锥面倒角标签一致。结构排除由“垂直支撑对 + 支撑面类型 + 单口端板”共同承担：

- 两个共轴圆壁之间的**结构锥度过渡**（如 stepped shaft 的锥面 01013305 f5/f6、f53/f54）找不到平面/圆柱垂直支撑对，被拒绝；
- 球头/旋钮类回转体（如 1.step）的锥面分片，其支撑邻居是球面/环面/同族锥面，被支撑面类型门拒绝；
- 两端被平板封住的结构锥壁（如 2.step f208）由两端端板门拒绝；
- 被钻孔的锥形毂（带内环，如 01013305 f51/f52）由内环门拒绝；
- 完整回转、恰好两个邻居、锥轴共轴、面积比例等旧约束均已移除；大锥台（01013042）、半环锥面（8.step）、多边形孔口角锥（12.step）、阶梯锥簇（01013304）在新判据下全部保留。

**圆柱窄条倒角**（曲面截面倒角的另一种形态，`_cylinder_strip_is_chamfer`）：沿直棱边的窄圆柱条（`u_span < 0.3` 弧度），且**径向必须向外**（`radial > 0`，凸的外棱去毛刺/倒圆），与至少一个平面的过渡角在 `chamfer_min_angle`–`chamfer_max_angle`（`18°–72°`）内。内凹的窄圆柱条（`radial < 0`，内角圆角/fillet）不是外棱倒角，被径向凸性门拒绝。壁状圆柱（凸台侧壁、圆壁之间的圆角）回转跨度远大于 0.3，或只以 `90°`/边缘角碰平面，也被拒绝。

特别规则：两个曲面之间的**平面**连接面不算倒角。例如圆柱面和另一个曲面之间的圆滑连接，即使看起来也是过渡区域，也不标记为 `chamfer`。普通的平面-平面倒角、平面-圆柱倒角仍然可以识别。torus 圆环面不作为倒角识别（它是圆角/blend，只作孔/凸台 pass 的过渡桥，保持 `other`）。

注：孔口的锥形过渡面被标为 `chamfer` 的同时，仍然充当孔 pass 的“过渡桥 carrier”证据（它把孔壁连接到内环 carrier），被它遮住的圆柱孔壁仍会被识别为 `hole`。

## 参数取值说明
### 参数设计原则
本程序中的参数分为三类：
1. **数值几何容差**：用于处理 STEP/B-rep 的分割、建模误差和尺度变化，应优先采用与模型包围盒尺寸相关的尺度化形式。
2. **候选生成阈值**：用于从复杂 B-rep 中宽松地筛选可能属于某个特征的面或面组，宁可保留少量歧义候选。
3. **结构确认与经验约束**：用于最终确认 feature，或抑制明显不符合目标零件范围的误识别。这类参数属于实现启发式，不是论文或 OCC 规定的标准值，应通过数据集继续标定。
### 推荐默认参数
下面给出当前使用的默认参数。除数值几何容差外，其余参数应理解为 feature-recognition heuristics；“默认值”是基于当前规则结构和几何常理给出的起点，而不是普适行业标准。
| 参数                               |     默认值 | 类型         | 作用                                                                                                        |
| ---------------------------------- | ---------: | ------------ | ----------------------------------------------------------------------------------------------------------- |
| `radial_threshold`                 |      `0.2` | 结构确认     | 判断圆柱/圆锥面的径向方向。小于 `-0.2` 认为是 inward，大于 `0.2` 认为是 outward，中间区间保留为 uncertain。 |
| `axis_alignment_threshold`         |      `0.7` | 候选生成     | 粗筛轴线和法向是否大致一致，使用单位向量点积绝对值。                                                        |
| `axis_alignment_confirm_threshold` |      `0.9` | 结构确认     | 对真正作为 boss 顶面等关键结构关系的轴向对齐进行更严格确认。                                                |
| `axis_distance_tolerance_ratio`    |   `1.0e-5` | 数值几何容差 | 判断多个圆柱是否共轴，按模型包围盒对角线缩放。                                                              |
| `hole_angular_coverage_tolerance`  | `0.05` rad | 闭合容差     | 判断多个圆柱孔壁合起来是否闭合成完整圆，以及盲孔底面圆弧累计是否闭合。                                      |
| `chamfer_min_angle`                |    `18.0°` | 候选生成     | 平面过渡面与支撑面之间锐角的宽松下限。                                                                      |
| `chamfer_max_angle`                |    `72.0°` | 候选生成     | 平面过渡面与支撑面之间锐角的宽松上限。                                                                      |
| `chamfer_preferred_min_angle`      |    `30.0°` | 置信度/确认  | 常见倒角角度范围的较严格下限。                                                                              |
| `chamfer_preferred_max_angle`      |    `60.0°` | 置信度/确认  | 常见倒角角度范围的较严格上限。                                                                              |
### 两级理解的实际落实
`axis_alignment_threshold = 0.7` 不再直接等同于“严格对齐”。它对应较宽松的候选筛选（carrier 搜索、cap/base 分类、闭合检查里的轴对齐平面边界等）；关键的顶面/端面确认使用 `axis_alignment_confirm_threshold = 0.9`（boss 顶面的几何判定：轴向对齐 + 位置约束）。
倒角角度按倒角形态使用不同区间：
- 锥形倒角：平面支撑角 `10°–80°`（锥面参考法向噪声大，区间最宽）；
- 圆柱窄条倒角：平面支撑角 `18°–72°`（`chamfer_min/max_angle`）；
- 平面倒角：两个支撑角都在 `30°–60°`（`chamfer_preferred_min/max_angle`），且两支撑面接近垂直。
当前实现是纯二值分类（没有置信度评分）。平面倒角不再使用任何面积/尺寸门，确认完全基于支撑几何（角度、接触边处的垂直度、条带边数）和固定点排序；锥形倒角与圆柱窄条倒角由各自的支撑 hint 单独确认。锥形/平面倒角的支撑面只取平面或圆柱（回转同族的锥/环/球面分片不算），圆柱支撑的法向取与候选面共享边处的径向方向，避免参数中点法向把平行圆柱误判成垂直。
### 其他固定辅助规则
- 孔 pass 的 wall 分组容差：半径差 `≤ max(模型对角线 * 1.0e-5, 1.0e-6)`；共轴判定使用轴向方向一致性（绝对轴向点积 `≥ 1 - axis_distance_tolerance_ratio`）和轴线间垂直距离。凸台侧壁环的同级合并同时要求共轴**且同半径**（`_coaxial_same_radius`）。
- 孔 pass 的过渡桥 carrier：只允许 wall 的直接邻居为 `cone` 或 `torus` 时跨一层，不做多跳。该限制用于保持局部性，避免 BFS 穿过过多过渡面把无关结构并入同一个 feature。
- 孔 pass 的盲孔底面判定沿轴分桶：共享圆弧按 `dot(center, axis)` 保留 6 位小数分桶；同桶累计参数跨度 `≥ 2π - hole_angular_coverage_tolerance` 才算“一张嘴”。
- 锥形倒角（`_cone_is_chamfer`）：不带内环、非退化（`u_span ≥ 0.05`、面积 `> 1.0e-9`）的圆锥面（不要求闭环），且不是两端都有端板的封闭锥台（`_cone_has_two_end_planes`，轴向两端各有一个法向平行于锥轴、偏移不同的平面邻居时拒绝）。存在两个与锥面成 `10°–80°` 的**平面或圆柱**支撑邻居、且彼此在共享边处的法向点积 `< 0.05`（垂直）。锥/环/球面同族分片不算支撑面。被 STEP 切开的同锥面分片由固定点同族传播补标。无合格垂直支撑对的结构锥度过渡（stepped shaft 锥面）、回转体球头分片、两端封闭锥壁被拒绝。
- 圆柱窄条倒角（`_cylinder_strip_is_chamfer`）：`u_span < 0.3` 且 `radial > 0`（外凸）的圆柱条，与至少一个平面的过渡角在 `chamfer_min_angle`–`chamfer_max_angle`（`18°–72°`）。`radial < 0` 的内凹窄圆柱是内角 fillet，被凸性门拒绝。该 `0.3`、凸性门与角度区间由数据集标定。
- 平面倒角（`_plane_is_chamfer`）**不使用任何面积门**：没有相对支撑面的 `0.15` 比例，没有中位面积/包围盒绝对上限，也没有 `chamfer_max_support_area_ratio`。判据是：该面自身不带内环（但贴着邻居内环边的孔口倒角不排除）；两个非倒角支撑面在 `30°–60°` 与该面相交；彼此在共享边处法向点积 `< 0.05`（真正垂直，约 ≥87°），且垂直对中至少一个是平面；`edge_count ≤ 6`。圆柱支撑面取共享边处径向法向而非参数中点法向，以排除平行圆柱被参考法向误判为垂直。支撑面可以是圆柱壁（含 outward 凸台侧壁，使侧壁↔顶面的平面倒角可被识别）。另加三角角帽规则、同族锥面传播与按面积升序的固定点迭代。`0.05`（垂直度误差）、`6`（条带最大边数）、`30°–60°` 支撑角是数据上的分离点。
- 倒角支撑法向的接触点取值（`_support_normal_at_contact`）：平面支撑用其恒定法向；圆柱支撑取候选面与该圆柱共享边中点处的径向法向（从圆柱轴投影到该点）。这样判断的是两个面实际相接棱处的夹角，而不是圆柱参数域中点的任意圆周法向——后者会把共轴/平行圆柱在不同圆周采样点上的法向误判为垂直。
- 凸台结构化 pass 中，侧壁法向与凸出轴的绝对点积需要小于等于 `0.35`，作为横向/正交的宽松主判据；顶面法向与凸出轴的绝对点积在最终确认时大于等于 `axis_alignment_confirm_threshold`（`0.9`）。凸出轴对平面 carrier 是 carrier 法向，对曲面 carrier（情形 D）是 cap 法向。
- 凸台侧壁不合并多级凸台：不同轴向级别（不同半径或轴线位置不同）的共轴 outward 圆柱侧壁不加入同一环；多级凸台会拆散为多个单级凸台分别判定。只有同一单级凸台被分割成的共轴同半径侧壁段允许合并。自由形状包围圈凸台放宽到同母线方向（`axis_dir` 一致）且该墙被 carrier 内环持有。
- 凸台主要面垂直且可被修饰：侧壁环面与顶面两个主要面必须相互垂直（以凸出轴为参照：侧壁横向，顶面轴向对齐），但两者无需完全相交；允许通过 cone/torus 过渡面相连，以计入凸台被倒角、圆角、孔、槽等特征修饰的情况。
- 凸台侧壁是否真的向外凸出，用面中心相对 carrier 沿凸出轴的有符号偏移判断，容差为 `max(模型包围盒对角线 * 1.0e-7, 1.0e-7)`；偏移符号由种子固定，环内所有侧壁必须与种子同向。
- 凸台顶面位置约束：顶面中心沿凸出方向的偏移必须严格大于所有侧壁环面的偏移（同样用上述容差）；顶面可经倒角/圆角桥间接连到侧壁，桥由 BFS 跨越，顶面用几何判定（严格轴向对齐 + 位置）确认。
- 凸台底面边界包含判定（情形 C）的共面容差为 `max(模型对角线 * 1.0e-6, 1.0e-6)`；底面外环多边形必须包含 cap 外边界全部采样点，且至少一个点严格落在内部。若**所有** cap 都能找到这样的更大包含面（两端都被更大表面接收，如两个零件之间的连接杆），则视为贯穿连接件、拒绝为凸台；必须至少有一个 cap 没有更大包含面（自由端）才承认。
- 凸台情形 B 的 cap/base 判定：侧壁共轴同族（同轴圆柱另一半等）视作“侧壁自身”，端面邻居平面的所有邻居都在共轴同族内才算 cap，否则算 base（外壁）。
- 凸台情形 D（曲面 carrier）：cap 法向作凸出轴；曲面邻居须带内环、与侧壁交叉轴（轴向点积 `< 0.9`），才作 carrier。
- 凸台情形 E（同轴法兰/凸缘）：环为同轴同半径 outward 圆柱（`u_span` 之和 `≥ 2π - hole_angular_coverage_tolerance`）；cap 为种子的轴对齐带内环平面邻居；杆为穿过 cap 内环圆角（cone/torus）的更细同轴 outward 圆柱（半径差 `> max(模型对角线 * 1.0e-5, 1.0e-6)`）。闭合检查允许环面邻接到 cap、杆、cone/torus 圆角、或轴对齐平面（头部开口的另一端，如开槽面）。比例约束 `2·R_head > 头部轴向厚度` 应理解为同轴法兰/头部的经验性形状先验：如果程序需要覆盖细长头部，建议改为置信度惩罚而不是唯一的硬拒绝条件。**carrier 判定**：底面为头部另一端（与 cap 相对）的轴对齐平面，从环或杆的轴对齐平面邻居（杆端可经一层 cone/torus 圆角）可达；按共面（法向平行 `≥ 1 - 1.0e-6`、轴向偏移 `≤ max(模型对角线 * 1.0e-5, 1.0e-6)`）做**全局**收集（非仅边相邻），测相对杆轴的最大径向范围，要求 `> R_head + max(模型对角线 * 1.0e-6, 1.0e-6)`（底面 > 包围面）；找不到底面或底面不大于头部则拒绝。实例 = 环 + cap；杆、圆角和底面不进入。
- 凸台情形 F（轴端实心旋钮）：环为共轴同半径 outward 圆柱（`u_span` 之和 `≥ 2π - hole_angular_coverage_tolerance`）；顶面为环一端的轴对齐平面（可隔一层 `chamfer` 锥面）；杆为环另一端经 cone/torus 圆角过渡接到的更细同轴 outward 圆柱（半径差 `> max(模型对角线 * 1.0e-5, 1.0e-6)`）。闭合检查允许环面邻接到顶面、杆、圆角、`chamfer` 或已认领面。carrier 复用情形 E 的底面判定。实例 = 环 + 顶面；杆、圆角和底面不进入。
- 凸台闭合检查允许环面邻接到与 carrier 共轴的曲面分片（split 圆柱 carrier 的另一半）。
- 凸台包住的凹陷壁：`inward` 圆柱壁当其所有邻居都在凸台结构（侧壁环 + 顶面 + carrier + 已收候选）内、且未被其他 pass 认领时，并入凸台实例；用 fixpoint 剔除碰到外表面的候选。cone/torus 圆角不再并入（只作桥接，保持原标签）。
- 凸台 carrier 可达性（情形 A'）允许跨过一个 cone/torus 过渡面：过渡面本身不作为 carrier，但是如果它的邻居中有带内环的面，就以那个面为 carrier。
- 凸台实例 = 侧壁环 + 顶面 + 包住的凹陷壁；倒角面（平面/锥面）保持 `chamfer`，cone/torus 过渡面保持原标签，carrier/底面不进入。
- 凸台闭合检查与盖子边界检查中，**已被认领的面**（hole/chamfer/其他凸台）算合法边界；凸台种子扫描做两轮，第二轮带着第一轮认领结果重扫，使边界邻接后识别凸台的种子也能闭合。
- 凸台比例约束“底面周长 / π > 高度”已移除（详见“比例约束（已移除）”一节）。
### 参数标定建议
上述默认值应作为初始配置，而不是最终固定常数。建议建立人工标注 STEP 数据集，分别统计 `hole`、`boss`、`chamfer` 的 TP、FP、FN，并重点扫描：
- `radial_threshold`：建议测试 `0.1–0.3`；
- `axis_alignment_threshold`：建议测试 `0.65–0.8`；
- `axis_alignment_confirm_threshold`：建议测试 `0.85–0.97`；
- `hole_angular_coverage_tolerance`：建议测试 `0.02–0.08 rad`；
- `chamfer` 支撑角范围（锥面 `10°–80°`、圆柱条 `18°–72°`、平面倒角 `30°–60°`）、平面倒角支撑面垂直容差（法向点积 `< 0.35`）、条带最大边数（`6`）、三角角帽规则；
- `0.35` 横向阈值；
- `4/8/0.025/0.08` 绝对面积尺度参数；
- 凸台主要面垂直容差与多级拆分的边界；
- `2·R_head > thickness` 等比例先验（`carrier perimeter / π > height` 已随比例约束移除）。

## 运行

使用 `conda run`，确保 OpenCASCADE 的 DLL 路径被正确激活。

`recognizer.py` 内部使用扁平导入（`from geometry import ...`），所以需要从 `mfr_recognizer` 包目录内运行，否则 `python -m mfr_recognizer.*` 会找不到 `geometry` 模块。

单文件识别（在 `mfr_recognizer/` 目录内）：

```powershell
cd mfr_recognizer
F:\miniforge\Scripts\conda.exe run -n mfr python -m cli ..\data\step\01010028.step --verbose
```

评估样本数据集（包目录内直接跑评估脚本，或用根目录的 `evaluate.py` 入口）：

```powershell
cd mfr_recognizer
F:\miniforge\Scripts\conda.exe run -n mfr python evaluate.py --dataset ..\data --details
```

批量生成预测标签：

```powershell
cd mfr_recognizer
F:\miniforge\Scripts\conda.exe run -n mfr python batch_predict.py --step-dir ..\data\step --out-dir ..\data\pred_label --overwrite
```

> 注：`python -m mfr_recognizer.cli` 这种从仓库根目录的模块调用方式因扁平导入暂时不可用，请在 `mfr_recognizer/` 目录内以脚本方式运行。
