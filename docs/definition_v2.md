# 制造特征定义 V2

本文件从当前识别规则（`mfr_recognizer/recognizer.py`，见 `README.md`）中反推三类制造特征的**操作性定义**。它不是 AP224 标准条文的翻译，而是识别器实际判定一个面属于 `hole / boss / chamfer` 时所依据的充要条件集合。

判定一律在 B-rep 面邻接图上进行：每个面记录面型、面积、中心、法向、轴向、U/V 跨度、径向方向、内外环邻居。识别顺序为 **hole → chamfer → boss**，先认领的面不被后续覆盖（first pass wins）。

---

## 1. Hole（孔，标签 1）

**定义**：从零件中移除的一段**圆柱体积**，其可检特征是一圈完整不断开的 `2π` 内向圆柱侧壁。

一个面集合属于 hole，当且仅当：

1. **侧壁组成**：一组 `inward` 圆柱面（径向 `< -radial_threshold = -0.2`），通过共享 edge BFS 相连，且两两**共轴同半径**（轴向一致、轴线重合、半径差 `≤ max(对角线·1e-5, 1e-6)`）。几何共轴但拓扑不相连的两段半圆不属于同一孔。
2. **闭合性**：组内所有面的 U 向跨度之和 `≥ 2π - 0.05`（完整圆周）。缺角半圆、U 形槽、1/4 圆角在此排除。
3. **入口 hint（carrier）**：侧壁必须能挂到一个基准面上——要么某侧壁出现在某面的**内环邻接**中（壁穿过 carrier 的孔），要么侧壁的直接邻居是 cone/torus 过渡面、且该过渡面挂在某 carrier 的内环中（倒角/圆角挡住入口，跨一层）。没有 carrier 的孤立圆柱片段不附加盲孔底面。
4. **盲孔底面（可选）**：当 carrier 存在时，与侧壁共享圆弧 edge 的平面，若这些圆弧半径与壁一致、按轴向 z 分桶后累计 `≥ 2π - 0.05`、且位于该平面的**外环**（平面沉在孔内而非嘴部 carrier），则该平面为盲孔底面。
5. **阶梯孔合并（可选）**：两个已确认孔若共享一块 shelf plane（它同时是一个孔的盲底、另一个孔的 carrier 邻接平面）且同轴，合并为一个实例，shelf 一并纳入。

**属于 hole 的面**：内向圆柱侧壁组 + 盲孔底面 + 阶梯孔 shelf。
**不属于**：入口大平面（mouth carrier）、cone/torus 过渡面（保留原标签）、多边形孔、纯平面侧壁开口、斜切穿实体的圆柱片段。

---

## 2. Chamfer（倒角，标签 3）

**定义**：两个**非共面、且彼此近似垂直**的正常表面之间的较小过渡面。过渡截面可以是平面（flat cross section）或圆锥面（不要求完整回转），也包括沿直棱边的窄圆柱条。

### 2.1 平面倒角

一个平面属于 chamfer，当且仅当：

1. 不带内环（带内环的面更可能是孔/凸台 carrier）；
2. 是拓扑条带：`edge_count ≤ 6`；
3. 存在两个**非倒角**邻居作为支撑面，各自与该平面的锐角落在 `30°–60°`；
4. 这两个支撑面彼此**垂直**：法向点积绝对值 `< 0.05`（约 `≥ 87°`）；
5. 不连接两个曲面（圆柱/曲面之间的平面连接面不算倒角）。

支撑面可以是平面或圆柱壁（含 outward 凸台侧壁，因此凸台侧壁↔顶面的平面倒角可被识别）。

**三角角帽补充规则**：三条边、三个邻居、且三个邻居都已是倒角、彼此两两不共边的三角面（三面角处三个倒角条交汇的角帽），补收为倒角。

**面积排序固定点**：平面倒角按面积升序迭代识别。小条带先被标记，被条带包围的大结构斜面随即失去非倒角的垂直支撑对而被排除——不需要任何面积门即可分开大斜面与窄倒角条。

### 2.2 锥形倒角

一个圆锥面属于 chamfer，当且仅当：

1. 不带内环（带内环的锥面是被钻孔的结构锥台/沉座）；
2. 非退化碎片：`u_span ≥ 0.05` 且面积 `> 1e-9`；
3. 存在两个支撑邻居，各自与锥面的锐角落在 `10°–80°`（锥面参考法向噪声大，区间比平面倒角宽）；
4. 这两个支撑面彼此**垂直**：法向点积绝对值 `< 0.05`。

**不要求闭环**：拐角处只覆盖局部弧段的不闭环锥面只要有一对垂直支撑即识别。两个共轴圆壁之间的结构锥度过渡（如阶梯轴锥面）因找不到垂直支撑对被排除；完整回转、恰好两邻居、锥轴共轴、面积比例等旧约束均已移除。

### 2.3 圆柱窄条倒角

一个圆柱面属于 chamfer，当且仅当：

1. 不带内环；
2. `u_span < 0.3`（沿直棱边的窄条，而非回转侧壁）；
3. 至少有一个平面邻居与其锐角落在 `18°–72°`。

**不属于 chamfer**：非垂直转角（如 75° 尖角）处的斜切面、连接两个曲面的平面、带内环的结构锥台、torus 圆角（保持 `other`，只作孔/凸台 pass 的过渡桥）。

## 3. Boss（凸台，标签 2）

**定义**：从某个基准表面**向外凸出**的闭合形状，必须同时具备三部分：闭合侧壁环 + 盖住环的顶面 + 凸出所依附的底面（carrier，本身不进入实例）。三部分缺一不可。

一个面集合属于 boss，当且仅当：

### 3.1 侧壁环

1. **种子**：`outward` 圆柱面（径向 `> 0.2`），或被某个内环 carrier 持有、相对 carrier 正向偏移的平面侧壁；
2. **横向性**：环内每个面的法向与凸出轴近似正交（绝对点积 `≤ 0.35`）；
3. **同级约束**：圆柱侧壁之间须共轴同半径才合并（同一级凸台被 STEP 拆分的碎片）；不同半径或不同轴位的共轴圆柱属不同级，各自独立成实例。允许穿过 cone/torus 过渡桥去认领桥另一侧的同级碎片；
4. **凸出方向一致**：环内所有面相对 carrier 沿凸出轴的有符号偏移与种子同向（容差 `max(对角线·1e-7, 1e-7)`）。

### 3.2 闭合性

环上每个面的每个非侧壁邻居，必须是以下之一：carrier、与 carrier 共轴的曲面分片、通向顶面的过渡面、环内另一面、穿台孔壁（内向圆柱/已标 hole）、或已被其他特征认领的面。带内环的邻居只有当它正是盖住环的顶面时才合法，否则视为环漏到外表面，拒绝。

### 3.3 顶面

1. **位置**：与凸出轴严格对齐（法向点积绝对值 `≥ axis_alignment_confirm_threshold = 0.9`），且顶面中心沿凸出方向的偏移严格大于所有侧壁环面（顶面在侧壁外侧）；
2. **边界不溢出**：顶面及其包住的凹陷壁组成的盖子，其外边界最多与侧壁顶边重合；盖子邻居只能是侧壁环、carrier、盖内面、穿顶孔壁或已认领面（含 chamfer collar）。顶面可隔着已标注的 chamfer 锥面连到侧壁，但倒角面本身不并入 boss；
3. **可带内环**（孔穿过顶面）仍合法。

### 3.4 底面（carrier）与凸出方向

凸台与凹槽在结构上对称，唯一区别是凸出方向为正（侧壁中心在 carrier 法向正侧）。carrier 按以下情形确定：

- **A（内环 carrier）**：侧壁被某带内环面直接持有；
- **A'（过渡桥 carrier）**：侧壁经一个 cone/torus 过渡面挂到带内环 carrier；
- **B（外壁拒绝）**：侧壁通过基准面外环连接、且该面扩展到共轴同族之外——是零件外壳自身的壁，拒绝；
- **C（独立圆柱/装配）**：两端均为 cap、无拓扑相连底面时，几何搜索一个与 cap 共面、外环严格包含 cap 连接圆的更大平面作为底面；**同时要求另一端是自由端**——至少一个 cap 找不到这样的包含面。两端都被更大表面接收的（如两个零件之间的连接杆）是贯穿连接件，拒绝；
- **D（曲面 carrier）**：侧壁从非平面本体（如圆柱件）经外环凸出，带内环且与侧壁交叉轴（轴向点积 `< 0.9`）的曲面邻居为 carrier，凸出轴取 cap 法向；
- **E（同轴法兰/凸缘）**：一圈同轴 outward 圆柱合成完整 `2π`，被带内环的轴对齐 cap 盖住，cap 内环孔让更细同轴 outward 杆穿过；carrier 是头部另一端的轴对齐底面，全局收集共面碎片后要求其最大径向范围大于头部半径；
- **F（轴端实心旋钮）**：同 E，但顶面实心、杆在环另一端经圆角过渡接到更细同轴 outward 杆；carrier 复用 E 的底面判定。

### 3.5 包住的凹陷壁

被凸台结构完全包围的**内向圆柱**凹陷壁（如线轴形凸台颈部凹槽）并入实例；BFS 收集后用 fixpoint 剔除任何碰到外表面的候选。cone/torus 过渡面**不并入**（保持 chamfer/other）。

**属于 boss 的面**：侧壁环 + 顶面 + 被包住的内向凹陷壁。
**不属于**：carrier/底面、chamfer 过渡面、凹槽（凸出方向为负）、外壳外壁（Case B）、两端接收的贯穿连接件（Case C 拒绝）、环不闭合或顶面溢出侧壁的结构。

---

## 4. Other（其他，标签 0）

不属于上述三类的所有面：零件主体大平面、外壳外壁、torus 圆角、结构锥度过渡、非垂直转角处的斜切面、未闭合的圆柱片段、自由曲面外表面等。

## 附：判定优先级与容差一览

| 项目 | 取值 |
|---|---|
| 识别顺序 | hole → chamfer → boss，first pass wins |
| 径向内外向阈值 | `±0.2` |
| 轴线粗筛对齐 | `0.7` |
| 顶面/关键结构严格对齐 | `0.9` |
| 共轴/半径容差 | `max(对角线·1e-5, 1e-6)` |
| 圆周闭合容差 | `0.05 rad` |
| 平面倒角支撑角 | `30°–60°`，支撑面垂直 `|dot|<0.05`，边数 `≤6` |
| 锥形倒角支撑角 | `10°–80°`，支撑面垂直 `|dot|<0.05`，`u_span≥0.05` |
| 圆柱窄条倒角 | `u_span<0.3`，支撑角 `18°–72°` |
| 侧壁横向性 | 法向与凸出轴 `|dot|≤0.35` |
| Case C 共面包含容差 | `max(对角线·1e-6,1e-6)` |
| Boss 种子扫描 | 两轮（第二轮携带第一轮认领结果重扫） |
